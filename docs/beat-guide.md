## 앱 매핑

- `beatIndex` 0~14 = 위 표 순서
- Top(`RouteNav`) 프로그레스·칸반 열·퀵 스크롤은 이 인덱스를 사용한다
- 짧은 안내: `guidanceKo` (프로그레스 라벨·헤더 툴팁)
- 핵심 질문: `promptsKo` (헤더 툴팁)
- 상세: `purposeKo` / `detailKo` / `tipsKo` / `avoidKo` → 인포 아이콘 · `BeatGuideModal`
- 1·2·3막: `ACT_GUIDE`로 칸반 열·프로그레스 구간 표시
- 데이터 소스: `src/data/beatGuide.ts` (폴더의 `beats/guide.json`으로 덮어쓰기 가능)
