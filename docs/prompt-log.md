### 2026-07-27 — 씬 UX 재정의 (확인 후 구현)

- **요청 요지:**
  1. HTML 리치 에디터(ToastUI류) — TipTap 유지
  2. +씬 시 별도 하단 패널이 아니라 **그 자리에 입력 카드 생성**
  3. 씬 클릭 → 편집 모드 / 바깥 클릭 → 종료
  4. 편집 모드에서만 에디터 툴바(굵게·이미지 등)
  5. DnD로 이동 + ⋯(더보기) 메뉴로 맨위/위/아래/맨아래/왼/오
- **대응:** `SceneCard` 인라인 편집, `SceneEditor` 제거, `@dnd-kit` DnD, `nudgeScene`/`placeScene`, 툴바 조건부
